## Лабораторная работа №10

1. **Состояние сна при `accept()`**  
   Сервер потребляет 0% CPU, потому что при отсутствии входящих подключений поток переходит из состояния **Running** в состояние **Waiting/Sleeping**. Планировщик ядра не выделяет такому потоку процессорное время, пока не произойдет событие — например, новое сетевое подключение.

2. **Почему порт занят после закрытия сервера**  
   После завершения работы сервера в сетевых таблицах ядра могут оставаться соединения в состоянии **`TIME_WAIT`**. Это временное состояние нужно для корректного закрытия TCP-соединения и защиты от старых пакетов. Поэтому порт может оставаться занятым даже после закрытия программы.

3. **Что делает `SO_REUSEADDR`**  
   Флаг `SO_REUSEADDR` разрешает новому сокету привязываться к порту, даже если на нем еще остались соединения в состоянии `TIME_WAIT`. Это позволяет быстро перезапускать сервер без ошибки `Address already in use`.
